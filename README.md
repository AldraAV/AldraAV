## Sobre Mí

Soy estudiante de **Ingeniería en Tecnologías de la Información y Comunicaciones (TICs)** con fuerte afinidad por la electrónica, los semiconductores y todo ese rollo.

Acá la rolo de **desarrollador web y a lo mejor un vibecodero pero muy honesto**: me gusta crear interfaces, conectar o crear servicios, automatizar tareas así bien castrozonas o que se me ocurrieron y resolver problemas cotidianos con código.

No lo sé todo, hijo. Pero aquí andamos, aprendiendo, probando librerías, experimentando ocasionalmente con C++ o Rust cuando el rendimiento lo pide, y jugando con cosas cuando podemos hacer algo más eficiente
